Box-Sizing Comparison

Understanding the difference between content-box and border-box

Default: content-box

The total width = content + padding + border.

box-sizing: border-box

The total width includes content, padding, and border within the set width.

How Box-Sizing Affects Layout

By default, elements use content-box — the width and height only apply to the content area. Padding and border are added outside, increasing the total size.

When using border-box, padding and borders are included inside the defined width and height, making layout design more predictable and easier to manage.
